# Qt报警中心模块运行说明

## 1. 模块用途

报警中心模块用于在一个独立页面中查看系统中的全部报警记录，并支持筛选和确认。

完成后你可以做到：

1. 不进入某个具体病人，也能直接查看所有报警。
2. 按病人、级别、状态筛选报警。
3. 在报警中心页查看报警详情。
4. 在报警中心页直接确认报警。

## 2. 前置条件

需要保证以下程序可正常运行：

1. `business_service`
2. `graduation_project_widget`

如果希望看到真实报警数据，还需要保证系统中已经产生过至少一条异常监测记录。

## 3. 启动顺序

建议按以下顺序启动：

1. 启动 `business_service`
2. 启动 Qt 客户端
3. 登录系统
4. 在病人页点击“报警中心”
5. 刷新全局报警列表
6. 筛选并确认报警

## 6. 页面使用步骤

### 6.1 进入报警中心

1. 登录 Qt 客户端。
2. 进入病人管理页。
3. 点击表格上方的“报警中心”按钮。
4. 主窗口会切换到报警中心页。
5. 页面会自动刷新病人列表和全局报警列表。

### 6.2 筛选报警

你可以使用以下筛选条件：

1. 关键词：病人编号、病人姓名、预测标签、样本名。
2. 级别：`critical / warning`
3. 状态：`new / confirmed`

如果想重新拉取服务端最新数据，点击：

```text
刷新报警
```

### 6.3 确认报警

1. 在报警中心表格中选中一条状态为 `new` 的报警。
2. 点击“确认选中报警”。
3. 在确认框中点击“是”。
4. 成功后页面会自动刷新。

确认后你会看到：

1. `status` 从 `new` 变成 `confirmed`
2. `confirmed_at` 被写入时间
3. `confirmed_by` 被写入当前登录用户

### 6.4 查看报警详情

你可以通过以下两种方式打开详情：

1. 先选中一条报警，再点击“查看报警详情”。
2. 直接双击某一条报警记录。

弹窗中会显示：

1. 病人基础信息
2. 报警编号和时间
3. 预测标签、置信度、来源、样本名
4. 报警状态、确认时间、确认人

### 6.5 返回病人管理

点击：

```text
返回病人管理
```

即可回到病人页。

## 8. 常见问题

### 8.1 报警中心页是空的

优先检查：

1. 是否还没有产生任何异常报警。
2. 业务服务端是否已启动。
3. 是否已经登录业务服务端。
4. 当前业务数据目录是否正确。

### 8.2 病人姓名显示为 `-`

原因通常是：

1. 报警列表已拉到，但病人列表还没同步完成。
2. 当前报警对应的病人数据不在本次病人列表中。

一般点击“刷新报警”后会恢复正常。

### 8.3 点击确认没有效果

优先检查：

1. 当前选中的报警是否已经是 `confirmed`。
2. 当前登录用户是否为空。
3. 业务服务端日志中是否返回 `ERR`。
