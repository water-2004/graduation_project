# 论文算法优化技术说明

## 1. 模块目标

本模块对参考论文的 STFT+2D-CNN 模型进行训练优化，在不改变模型输入输出形状的前提下，通过训练技巧提升 Macro-F1 等核心指标，使论文算法在答辩中展示出清晰的优化过程。

## 2. 优化背景

当前参考论文模型（脚本09）的 Macro-F1 为 0.8500，低于 Random Forest 的 0.8993。主要瓶颈在于：

1. 模型缺少归一化层，训练不稳定。
2. 损失函数未考虑类别不平衡，少数类召回偏低。
3. 学习率固定，后期可能过大导致验证指标震荡。
4. 缺少权重衰减正则化。
5. 训练轮数偏少（50轮），模型可能未充分收敛。

## 3. 优化方案

### 3.1 BatchNorm2d

在每个 Conv2d 层后插入 BatchNorm2d，对特征图做归一化：

- 加速训练收敛
- 提供正则化效果，减少过拟合
- 参考脚本03中 BatchNorm1d 的使用模式

优化前：

```
Conv2d → ReLU → MaxPool2d
```

优化后：

```
Conv2d → BatchNorm2d → ReLU → MaxPool2d
```

### 3.2 类别权重损失函数

使用 sklearn balanced 公式计算类别权重：

```
weight_i = total_samples / (n_classes * count_i)
```

将权重传入 `nn.CrossEntropyLoss(weight=class_weights)`，使模型对少数类（类别1、类别3）给予更多关注。

### 3.3 学习率调度

使用 `ReduceLROnPlateau`：

- 监控指标：验证集 Macro-F1
- 模式：`max`
- patience：5 轮无改善后降低学习率
- factor：每次乘以 0.5

### 3.4 权重衰减

在 Adam 优化器中增加 `weight_decay=1e-4`（脚本09为 0），提供 L2 正则化。

### 3.5 增加训练轮数

从 50 轮增加到 80 轮，配合学习率调度器充分训练。

## 4. 模型架构对比

### 4.1 基线模型（脚本09 ReferenceECGCNN）

```
Conv2d(1→16, k=3, p=1) → ReLU → MaxPool2d(2)
Conv2d(16→32, k=3, p=1) → ReLU → MaxPool2d(2)
Conv2d(32→64, k=3, p=1) → ReLU → AdaptiveAvgPool2d(1,1)
Flatten → Dropout(0.3) → Linear(64→5)
```

### 4.2 优化模型（脚本11 OptimizedReferenceECGCNN）

```
Conv2d(1→16, k=3, p=1) → BatchNorm2d(16) → ReLU → MaxPool2d(2)
Conv2d(16→32, k=3, p=1) → BatchNorm2d(32) → ReLU → MaxPool2d(2)
Conv2d(32→64, k=3, p=1) → BatchNorm2d(64) → ReLU → AdaptiveAvgPool2d(1,1)
Flatten → Dropout(0.3) → Linear(64→5)
```

模型仅在卷积块中增加了 BatchNorm2d，其余结构完全一致。

## 5. C++ 兼容性说明

### 5.1 输入形状不变

STFT 参数保持 `nperseg=32, noverlap=16`，信号长度为 187 点，输出时频图形状为 `[1, 1, 17, 11]`。

### 5.2 推理引擎自动适配

C++ `InferenceEngine` 构造时检测 ONNX 模型输入 rank：

- rank=3 → `raw_1d_cnn` 模式
- rank=4 → `paper_reference_stft_2dcnn` 模式

优化后模型输入仍为 rank=4，自动走 STFT 前处理路径。

### 5.3 无需修改 C++ 或 Qt 代码

只需将 `artifacts/paper_optimized_cnn/model_best.onnx` 替换到 `edge_infer_service` 的模型路径即可。

## 7. 已知限制

1. 当前数据仍为 187 点单拍形式，无法构造论文所述的 10 秒重叠窗口。
2. BatchNorm2d 在 ONNX 导出时会被折叠到卷积层中，不会增加推理耗时。
3. 类别权重仅在训练阶段使用，推理阶段不涉及。
4. 学习率调度器状态不保存到模型文件中，仅用于训练过程。

## 8. 下一步建议

1. 如果优化后 Macro-F1 仍低于传统模型，可尝试增加数据增强或调整网络深度。
2. 后续可在对比报告中增加推理耗时对比。
3. 可考虑模型集成（CNN + 传统模型）作为进阶方案。
