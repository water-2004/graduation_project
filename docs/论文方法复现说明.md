# 论文方法复现说明

## 当前结论

本项目现阶段已经完成了系统闭环，但算法部分还没有达到“严格复现论文”的程度。

你参考的论文是：

- Reliable ECG Anomaly Detection on Edge Devices for Internet of Medical Things Applications

结合论文原文，目前可以明确：

1. 论文中的 CNN 不是现在项目里的 1D-CNN。
2. 论文先把 ECG 信号做 STFT，转成时频图。
3. 然后论文使用 2D-CNN 做分类。
4. 训练完成后，论文还做了剪枝和量化，用于边缘设备部署。

所以，如果你后面要和老师严谨说明，应该说：

“当前系统已经完成了工程闭环，现有 1D-CNN 主要作为工程基线模型。为了贴近论文方法，后续新增了基于 STFT + 2D-CNN 的论文风格模型，并将继续补做剪枝、量化和部署验证。”

## 本项目当前的三层算法状态

### 1. 工程基线模型

对应文件：

- [03_train_cnn.py](F:/graduation_project/scripts/03_train_cnn.py)

特点：

- 输入是 187 点单拍心电数据。
- 模型是轻量 1D-CNN。
- 已导出 ONNX。
- 已接入 C++ 边缘推理服务。
- 适合先把系统跑通。

### 2. 对比实验模型

对应文件：

- [05_train_random_forest.py](F:/graduation_project/scripts/05_train_random_forest.py)
- [06_train_xgboost.py](F:/graduation_project/scripts/06_train_xgboost.py)
- [07_compare_models.py](F:/graduation_project/scripts/07_compare_models.py)

作用：

- 用统一数据集比较不同模型效果。
- 用于回答老师“为什么选这个模型”。
- 当前全量实验结果表明，随机森林与 XGBoost 的指标都优于现有 1D-CNN 基线。

### 3. 论文风格近似复现模型

对应文件：

- [08_train_paper_style_cnn.py](F:/graduation_project/scripts/08_train_paper_style_cnn.py)

已靠近论文的部分：

- 使用 STFT 做时频变换。
- 使用 2D-CNN 做分类。
- 卷积核大小为 3。
- 包含池化层、Dropout、全连接层。
- 默认训练参数设置为 Adam、学习率 0.001、批大小 32、50 轮。

还没有完全做到的部分：

- 还没有改成论文中的 10 秒滑动窗口输入。
- 还没有加入 SMOTE 数据平衡流程。
- 还没有做剪枝。
- 还没有做量化。
- 还没有做该模型在香橙派上的真实部署验证。

## 建议你后续的顺序

1. 先跑 `08_train_paper_style_cnn.py`，拿到论文风格模型的第一版结果。
2. 将其与 1D-CNN、Random Forest、XGBoost 做对比。
3. 如果论文风格模型效果足够好，再继续做剪枝和量化。
4. 如果最终要部署到板子上，再考虑把该模型导出到边缘端推理链路中。
