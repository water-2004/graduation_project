# 毕业设计范围说明（MVP）

## 1. 目标
构建一个可演示、可联调、可答辩的边缘 ECG 监测系统，端到端具备以下能力：
- ECG 数据流输入（MIT-BIH 数据回放）
- 边缘侧异常推理
- 异常告警触发
- Qt 桌面端实时可视化
- SQLite 本地持久化

## 2. 范围内功能（必须完成）
1. 基于 `MIT-BIH/mitbih_train.csv` 与 `MIT-BIH/mitbih_test.csv` 的数据回放
2. 滑动窗口预处理（标准化 + 可选简单去噪）
3. 边缘节点轻量化模型推理（ONNX/C++）
4. 基础告警分级（warning/critical）
5. 边缘服务端与 Qt 客户端的 TCP 通信
6. 实时波形显示 + 最新预测结果 + 告警弹窗
7. SQLite 存储推理记录与告警事件
8. 网络不稳定场景下的基础重连与本地缓冲

## 3. 范围外功能（本月不做）
1. 移动端 App（Android/iOS）
2. 完整云平台与多租户账号体系
3. 复杂密码学体系与全流程合规系统
4. ECG 之外的多传感器融合（血氧、血压等）
5. 复杂分布式部署

## 4. 验收标准
- 端到端时延（边缘推理到客户端告警）：弱网模拟下 <= 1000 ms
- 边缘单窗口推理时延：目标 <= 20 ms
- 模型评估指标：输出 Accuracy、Macro-F1、各类别 Recall
- 稳定性：连续运行 >= 24 小时不崩溃（最低演示标准）
- 数据可追溯：SQLite 中可查询告警事件与推理结果

## 5. 四周里程碑
- 第 1 周：数据探查 + 基线模型训练 + ONNX 导出
- 第 2 周：C++ 边缘流水线（回放/预处理/推理）
- 第 3 周：TCP 协议通信 + Qt 客户端 + SQLite 日志
- 第 4 周：系统联调测试 + 弱网测试 + 论文图表整理

## 6. 交付物
1. 源代码（edge + client + scripts）
2. 训练模型文件（`models/*.onnx`）
3. 数据探查与评估报告（`results/*.md`）
4. 演示视频或截图
5. 论文可用图表与实验指标表
