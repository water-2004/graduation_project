# Qt 报警详情弹窗运行说明

## 1. 功能用途

报警详情弹窗用于查看单条报警的完整内容，便于演示和排查。

你可以在弹窗中看到：

1. 报警级别
2. 报警时间
3. 预测标签与置信度
4. 来源与样本名
5. 报警状态
6. 确认时间与确认人
7. 对应病人的基础信息

## 2. 前置条件

需要以下程序已经可以正常运行：

1. `business_service`
2. `graduation_project_widget`

并且系统中至少已经存在一条报警记录。

## 3. 使用步骤

### 3.1 进入报警中心

1. 启动 Qt 客户端并登录。
2. 进入病人管理页。
3. 点击“报警中心”按钮。
4. 等待全局报警列表刷新完成。

### 3.2 查看详情

方式一：

1. 在表格中选中一条报警。
2. 点击“查看报警详情”。

方式二：

1. 在表格中直接双击一条报警。

### 3.3 关闭详情

点击弹窗底部“关闭”即可返回报警中心页。

## 4. 我这次补充后的交互效果

现在报警中心页已经形成如下链路：

1. 查看全局报警
2. 本地筛选报警
3. 查看单条报警详情
4. 确认报警

这样你在答辩时就可以直接演示：

1. 系统收到异常报警。
2. 在报警中心快速定位。
3. 打开详情弹窗查看完整上下文。
4. 由登录用户完成确认处理。

## 5. 常见问题

### 5.1 为什么病人信息显示不全

通常说明当前报警对应的病人没有在本次病人列表缓存中找到。

可以先点击“刷新报警”，让页面重新同步病人列表和报警列表。

### 5.2 为什么“查看报警详情”按钮点不了

因为当前没有选中任何报警行。

先在表格中点选一条报警，再点击按钮。

### 5.3 双击没有反应怎么办

优先检查：

1. 当前表格中是否真的有报警数据。
2. 是否选中了空白区域而不是有效数据行。
3. Qt 客户端是否为最新编译版本。
