# 论文算法复现路线图

## 一、总体定位

本毕业设计后续应当明确以参考论文的方法为主线推进。

参考论文：

- Reliable ECG Anomaly Detection on Edge Devices for Internet of Medical Things Applications

当前最合理的项目定位如下：

- 主算法：复现论文中的 `STFT + CNN + 边缘部署优化` 路线
- 对比算法：`1D-CNN`、`Random Forest`、`XGBoost`
- 工程系统：Qt 客户端 + 边缘端推理服务 + MIT-BIH 模拟采集链路

这样安排的好处是：

1. 文献参考和算法主线一致。
2. 已做的对比实验可以直接保留，不会浪费。
3. 系统工程和算法研究两条线都能交代清楚。

## 三、论文算法应该拆成哪几个步骤复现

### 第一步：重新梳理论文方法链路

你的目标不是只记住“用了 CNN”，而是要明确论文完整流程。

建议你把论文方法拆成下面这条链：

1. ECG 原始信号输入
2. 信号预处理
3. STFT 时频变换
4. 构造二维时频图
5. 2D-CNN 分类
6. 模型评估
7. 模型压缩
8. 边缘端部署验证

你后面不管是写论文，还是向老师汇报，都按这个顺序说。

### 第二步：先把“核心算法复现”做出来

所谓核心算法复现，至少要做到：

1. 输入 ECG 信号
2. 做 STFT
3. 得到二维时频图
4. 用 CNN 做分类
5. 输出实验指标

这一部分你已经开了头，现在最关键的是把它继续做扎实，而不是停留在“能跑起来”。

### 第三步：继续向论文细节靠拢

要更接近论文，还要继续补：

1. 更接近论文的数据切片方式
2. 类别不平衡处理
3. 论文里的模型压缩思路
4. 论文里的边缘部署思路

这一步不是必须一次做完，但至少要完成其中 1 到 2 个关键点，论文说服力才会更强。

## 四、接下来你应该按什么顺序做

下面这个顺序最稳。

### 阶段 1：把论文风格模型做成“正式主模型”

你当前应该优先做这几件事：

1. 固定论文风格模型的输入方式
2. 调整 STFT 参数
3. 调整 CNN 结构与训练轮数
4. 重新做正式训练
5. 观察测试集 `Macro-F1`、`Macro-Recall`、各类别召回率

这一步的目标不是立刻超过随机森林，而是先让论文主模型稳定下来。

### 阶段 2：让论文模型和对比模型形成完整实验章节

你应该把实验设计整理成固定结构：

1. 论文风格模型
2. `1D-CNN` 基线模型
3. `Random Forest`
4. `XGBoost`

统一比较：

- Accuracy
- Macro-F1
- Macro-Recall
- 各类别召回率
- 是否适合边缘部署

这一步做完，你的实验章节就基本成型了。

### 阶段 3：补一个“更接近论文”的改进点

建议从下面三项里选一项优先做：

1. 类别不平衡处理
2. 更接近论文的数据窗口方式
3. 模型压缩或轻量化说明

如果时间有限，优先建议：

- **类别不平衡处理**

因为它最容易显著改善 `Macro-F1`，并且很好解释。

### 阶段 4：最后再考虑部署取舍

到最后你再决定：

1. 论文模型作为“论文主模型”
2. 现有 `1D-CNN` 作为“系统演示部署模型”

这两个模型不一定必须完全相同。

如果老师不强求“论文模型必须已经部署到板子”，那你完全可以这样写：

- 论文主模型：论文风格 `STFT + 2D-CNN`
- 工程演示模型：当前已接入系统链路的 `1D-CNN`

如果后面时间够，再考虑把论文模型继续接到边缘端。

## 五、你现在最应该做的具体任务

按优先级排序如下：

### 任务 1：优化论文风格模型

目标：让论文主模型结果更可信。

你要做的具体事情：

1. 调 STFT 参数
2. 调 batch size 和 epoch
3. 观察哪些类别 Precision 很低

### 任务 2：补类别不平衡处理

因为你当前论文风格模型的问题很明显：

- 异常能报出来

这通常和类别不平衡强相关。

你可以考虑：

1. 加类别权重
2. 重采样
3. 后续再看是否需要更复杂的方法

### 任务 3：整理实验章节表格

你现在已经有多个模型结果，应该尽快整理成表格。

| 1D-CNN | ... | ... | ... | 工程基线 |

## 六、毕设正文建议写法

下面这部分你可以直接改进后放进论文正文。

### 1. 研究思路写法

本课题以心电异常识别为研究对象，结合边缘计算场景，设计并实现了一套集数据处理、模型训练、边缘推理与可视化展示于一体的心电异常检测系统。算法部分以参考论文《Reliable ECG Anomaly Detection on Edge Devices for Internet of Medical Things Applications》为主线，重点复现其中基于时频分析与卷积神经网络的心电异常识别方法。同时，为验证所复现方法的有效性，本文还引入 1D-CNN、随机森林和 XGBoost 等模型作为对比算法，在统一数据集上进行实验分析。

### 2. 算法主线写法

参考论文的方法并非直接对原始一维心电信号进行卷积分类，而是先通过短时傅里叶变换将 ECG 信号转换为二维时频图，再利用卷积神经网络提取时频特征并完成异常分类。因此，本文在算法实现中重点围绕 STFT 特征构造、二维卷积网络设计及其实验验证展开。

### 3. 对比实验写法

为了更客观地评价论文方法在本课题场景下的适用性，本文在相同数据集和统一评价指标下，引入 1D-CNN、随机森林和 XGBoost 作为对比模型。评价指标包括准确率、宏平均 F1 值、宏平均召回率以及各类别召回率。通过对比实验，可以分析论文方法与传统机器学习方法、轻量深度学习方法之间的差异，并据此评估不同模型在边缘医疗场景中的应用潜力。

### 4. 当前阶段写法

目前，系统工程框架已经完成，包含 Qt 客户端、边缘端推理服务和模拟采集链路。算法方面，已完成多个对比模型训练，并实现了论文风格的 STFT + 2D-CNN 模型第一版。实验结果表明，传统树模型在当前数据表示下具有较好的综合指标，而论文风格模型在异常类召回方面表现较好，但仍存在误报偏高的问题，后续将继续从数据表示和模型优化角度进行改进。
