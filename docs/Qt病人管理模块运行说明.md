# Qt病人管理模块运行说明

## 1. 前置条件

运行病人管理模块前，需要保证以下条件满足：

1. 业务服务端已经编译完成。
2. Qt 客户端已经编译完成。
3. 业务服务端监听端口与 Qt 登录页填写的一致。
4. 默认账号存在：`admin / 123456`。

## 2. 启动顺序

建议启动顺序如下：

1. 启动业务服务端 `business_service`。
2. 启动 Qt 客户端 `graduation_project_widget.exe`。
3. 在 Qt 登录页输入业务服务端地址和端口。
4. 登录成功后进入病人管理页。
5. 选择病人后进入监测页。
6. 再连接推理服务 `edge_infer_service`。

## 3. 启动业务服务端

如果你已经在 `F:\graduation_project\build\cpp` 下完成过 CMake 配置，可以直接编译：

```powershell
cmake --build F:\graduation_project\build\cpp --config Release --target business_service
```

编译完成后，启动示例：

```powershell
F:\graduation_project\build\cpp\Release\business_service.exe
```

如果业务服务端使用默认配置，Qt 登录页可填写：

- 地址：`127.0.0.1`
- 端口：`9200`

## 4. 启动 Qt 客户端

如果你在 Qt Creator 中打开的是 `widget/graduation_project_widget/CMakeLists.txt`，可直接点击运行。

如果你希望命令行编译 Qt 客户端，可使用：

```powershell
cmd /c "call \"F:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat\" >nul && \"F:\Qt\Tools\CMake_64\bin\cmake.exe\" --build \"F:\graduation_project\widget\graduation_project_widget\build\Desktop_Qt_6_8_3_MSVC2022_64bit-Debug\" --parallel 1"
```

编译成功后可在下列目录找到可执行文件：

```text
F:\graduation_project\widget\graduation_project_widget\build\Desktop_Qt_6_8_3_MSVC2022_64bit-Debug\graduation_project_widget.exe
```

## 5. 登录与病人管理操作步骤

### 5.1 登录

1. 打开 Qt 客户端。
2. 在登录页输入业务服务端地址和端口。
3. 输入用户名和密码。
4. 点击“登录系统”。

默认账号：

```text
用户名：admin
密码：123456
```

### 5.2 查看病人列表

登录成功后会自动进入病人管理页，并自动拉取病人列表。

如果需要手动刷新，点击：

```text
刷新列表
```

### 5.3 新增病人

在病人表单中填写以下字段：

1. 病人编号。
2. 姓名。
3. 性别。
4. 年龄。
5. 联系电话。
6. 备注。

然后点击：

```text
新增病人
```

新增成功后：

1. 页面会提示成功信息。
2. 表单会清空。
3. 病人列表会自动刷新。

### 5.4 修改病人

1. 在病人表格中选择一个已有病人。
2. 页面下方表单会自动切换到编辑模式，并载入该病人信息。
3. 修改姓名、性别、年龄、电话或备注。
4. 点击“更新病人”。
5. 更新成功后列表会自动刷新。

说明：

- 当前版本把 `patient_id` 作为主键，编辑模式下不会修改病人编号。
- 如果要新增病人，请点击“清空表单”切回新增模式。

### 5.5 删除病人

1. 在病人表格中选择目标病人。
2. 点击“删除病人”。
3. 在确认框中点击“是”。

删除成功后，列表会自动刷新。

### 5.6 进入监测页

1. 在病人表格中选中目标病人。
2. 点击“进入监测”。
3. 主窗口切换到监测页。
4. 监测页顶部会显示当前病人信息。

如需返回病人管理页，点击：

```text
返回病人列表
```

## 6. 常见问题

### 6.1 登录失败

可能原因：

1. 业务服务端未启动。
2. IP 或端口填写错误。
3. 账号密码错误。
4. 业务服务端连接已断开。

### 6.2 病人列表为空

可能原因：

1. `business_service.db` 中当前还没有病人数据。
2. 业务服务端数据目录路径不正确。
3. 刚部署时还没有新增过病人。

### 6.3 点击新增无反应

优先检查：

1. 病人编号是否为空。
2. 病人姓名是否为空。
3. 业务服务端日志是否返回 `ERR`。

### 6.4 点击更新无反应

优先检查：

1. 是否已经先在病人表格中选中了一个病人。
2. 病人姓名是否为空。
3. 业务服务端日志中是否返回 `ERR`。

### 6.5 进入监测页后无法推理

这属于另一个链路问题，通常需要检查：

1. `edge_infer_service` 是否已启动。
2. Qt 监测页中的推理服务地址和端口是否正确。
3. 香橙派端的模型和 ONNX Runtime 是否部署完整。
