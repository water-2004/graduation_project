# 模拟采集与波形显示说明

## 1. 目标

当前系统不接入真实传感器，而是使用 `MIT-BIH` 导出的单拍样本文件模拟采集端输入。

整体流程如下：

1. Qt 客户端连接香橙派上的 `edge_infer_service`
2. Qt 发送 `LIST_SAMPLES` 获取可播放样本列表
3. 用户选择样本后，Qt 发送 `PLAY_SAMPLE <样本名>`
4. 香橙派读取对应样本，调用 ONNX 模型完成推理
5. 香橙派返回 `BEAT` 响应，包含：
   - 样本名
   - 真实标签
   - 预测类别
   - 置信度
   - 告警等级
   - 推理耗时
   - 187 个波形点
6. Qt 客户端接收后：
   - 回填波形点到文本框
   - 在波形控件中播放曲线
   - 更新预测结果与告警颜色

## 2. 新增协议

### 2.1 获取样本列表

请求：

```text
LIST_SAMPLES
```

响应：

```text
SAMPLES label_0_sample_1_idx_0.txt,label_1_sample_1_idx_18119.txt,...
```

### 2.2 播放单拍样本

请求：

```text
PLAY_SAMPLE label_0_sample_1_idx_0.txt
```

响应：

```text
BEAT name=label_0_sample_1_idx_0.txt true=0 pred=0 conf=0.982645 alert=normal latency_ms=0.279 values=1.000000,0.758264,...
```

## 3. 服务端启动方式

如果要启用样本播放功能，启动服务端时需要额外传入 `--sample-dir`：

```powershell
cd /d F:\graduation_project\build\cpp\Release
edge_infer_service.exe ^
  --model "F:\graduation_project\artifacts\cnn_mitbih_v2\model_best.onnx" ^
  --sample-dir "F:\graduation_project\results\qt_real_samples"
```

香橙派上同理，只需要把 `--sample-dir` 改成板子上的样本目录即可。

## 4. Qt 客户端变化

Qt 客户端新增了两部分界面：

1. `模拟采集` 区
   - `加载样本列表`
   - `播放样本`
   - 样本下拉框

2. `心电波形` 区
   - 使用自绘控件展示单拍 ECG 曲线
   - `normal / warning / critical` 使用不同颜色边框和波形颜色

## 6. 当前定位

这一版属于“模拟采集闭环 V1”：

- 已具备样本选择
- 已具备边缘推理
- 已具备波形显示
- 已具备告警联动

但还不是“连续实时推流”版本。

如果后续还要继续扩展，可以在此基础上再做：

1. 服务端主动推送连续波形点
2. Qt 实时滚动绘图
3. 多拍样本连续播放
4. 历史告警记录
