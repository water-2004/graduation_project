# QML 界面细化说明

## 本轮细化目标

本轮不是继续新增业务功能，而是对 QML 前端进行第二阶段打磨，重点解决以下问题：

- 页面按钮、输入框、下拉框样式分散
- 删除病人缺少确认步骤
- 页面切换和登录卡片缺少基础动效
- 部分页面的交互反馈不够统一

## 本轮新增组件

新增公共组件目录文件：

- `UI/Components/AppButton.qml`
- `UI/Components/AppTextField.qml`
- `UI/Components/AppTextArea.qml`
- `UI/Components/AppComboBox.qml`
- `UI/Components/ConfirmDialog.qml`

这些组件的作用如下：

### 1. AppButton

统一按钮风格，支持：

- `primary`
- `secondary`
- `danger`
- `success`
- `ghost`

同时支持：

- hover 颜色过渡
- 点击缩放反馈
- `compact` 紧凑模式

### 2. AppTextField

统一单行输入框风格，支持：

- 圆角输入框
- hover 边框变化
- focus 主色高亮
- 占位文字颜色统一

### 3. AppTextArea

统一多行输入框风格，主要用于：

- 监测页手动输入特征
- 病人备注输入

### 4. AppComboBox

统一下拉框样式，解决默认 Qt 控件风格和页面不统一的问题。

### 5. ConfirmDialog

统一确认弹窗样式，支持：

- 标题
- 说明文本
- 取消/确认按钮
- 弹出与关闭动画

## 页面级优化

### 登录页

文件：`UI/Pages/LoginPage.qml`

已完成：

- 接入统一输入框和主按钮
- 添加登录卡片淡入、上浮、缩放动画
- 保持默认测试账号展示
- 登录页视觉更接近现代医疗后台风格

### 病人管理页

文件：`UI/Pages/PatientPage.qml`

已完成：

- 搜索框改为统一输入组件
- 顶部操作按钮统一
- 行内按钮统一为紧凑型公共按钮
- 新增“删除病人确认弹窗”
- 抽屉编辑区改为统一表单控件
- 抽屉增加进入/退出动画

### 实时监测页

文件：`UI/Pages/MonitorPage.qml`

已完成：

- 连接参数区切换到统一输入控件
- 样本下拉框切换到统一下拉组件
- 操作按钮统一
- 手动特征输入改为统一多行输入框
- 进度条样式更统一
- 历史卡片增加 hover 上浮反馈

### 报警中心页

文件：`UI/Pages/AlertCenterPage.qml`

已完成：

- 搜索框与筛选框统一样式
- 归档按钮统一为主按钮
- 左侧报警卡片选中反馈更明显
- 右侧详情状态卡颜色切换更平滑

### 主壳页面

文件：`UI/Main.qml`

已完成：

- 增加背景装饰块
- 页面切换加入透明度 + 位移过渡动画
- 提升整体从一个页面切换到另一个页面时的连贯性

## 当前效果总结

经过这一轮处理后，前端不再只是“QML 能运行”，而是已经具备：

- 统一组件层
- 统一交互反馈
- 统一确认弹窗
- 统一输入风格
- 基础页面过渡动画

这意味着后续你继续扩展登录校验、报警详情、病历抽屉、消息提示等功能时，不需要再每个页面重复写一遍样式。

## 后续还可以继续细化的方向

如果继续做第三阶段前端优化，可以优先考虑：

1. 给 `TopBar` 增加通知面板和头像下拉菜单
2. 给 Dashboard 图表加数字滚动动画
3. 给监测页加播放/暂停/进度拖动控制条
4. 给报警页增加截图缩略图和处理备注输入区
5. 给整个系统增加明暗主题切换能力
