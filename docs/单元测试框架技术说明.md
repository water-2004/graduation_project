# 单元测试框架技术说明

## 1. 模块定位

为 C++ 后端服务引入 Google Test 单元测试框架，覆盖 SHA-256 哈希、业务逻辑层和数据仓库层的核心功能，确保后续迭代的回归安全。

## 2. 框架选型

- **Google Test v1.14.0**：通过 CMake `FetchContent` 自动拉取，不需要手动安装。
- 构建开关：`-DBUILD_TESTS=ON`（默认 OFF，不影响正常编译）。
- 测试运行：`ctest` 或直接执行测试二进制。

## 3. 测试目标

### 3.1 test_sha256

文件：`cpp/tests/test_sha256.cpp`

源文件依赖：`sha256.cpp`

测试用例：

| 用例 | 验证内容 |
|------|----------|
| EmptyString | 空字符串的 SHA-256 等于已知摘要 |
| KnownVector123456 | `123456` 哈希等于已知值 |
| KnownVectorHelloWorld | `Hello, World!` 哈希等于已知值 |
| DeterministicOutput | 相同输入产生相同输出 |
| DifferentInputsDifferentHashes | 不同输入产生不同输出 |
| OutputIs64HexChars | 输出为 64 字符小写十六进制 |
| IsSha256Hex_Valid | 合法哈希通过验证 |
| IsSha256Hex_TooShort | 短字符串不通过 |
| IsSha256Hex_UpperCase | 大写字符不通过 |
| IsSha256Hex_Plaintext | 明文密码不通过 |

### 3.2 test_business_logic

文件：`cpp/tests/test_business_logic.cpp`

源文件依赖：`business_logic.cpp`、`file_repository.cpp`、`sha256.cpp`、`logger.cpp`

每个测试用例在临时目录创建独立的 SQLite 数据库，测试完成后自动清理。

测试用例：

| 用例 | 验证内容 |
|------|----------|
| Ping | PING 返回 PONG |
| PingCaseInsensitive | 命令不区分大小写 |
| Quit | QUIT 设置 close_conn = true |
| EmptyCommand | 空命令返回 ERR |
| UnknownCommand | 未知命令返回 ERR |
| LoginWithDefaultUser | 默认 admin/123456 可登录 |
| LoginWrongPassword | 错误密码返回 ERR |
| LoginMissingFields | 缺少参数返回 ERR |
| AddAndListPatients | 添加病人后可查询到 |
| GetPatient | 按 ID 查询病人详情 |
| GetPatientNotFound | 查询不存在的病人返回 ERR |
| UpdatePatient | 更新病人信息 |
| DeletePatient | 删除病人后查询不到 |
| AddMonitorRecordAndList | 添加监测记录并查询 |
| AddMonitorRecordWithAlert | 严重级别记录自动生成报警 |
| ConfirmAlert | 确认报警记录 |
| ChangePassword | 修改密码后用新密码登录 |
| ChangePasswordWrongOld | 旧密码错误时修改失败 |

## 4. 构建与运行

```bash
# 配置（启用测试）
cmake -B build -DBUILD_TESTS=ON -DONNXRUNTIME_ROOT=... -DBOOST_ROOT=...

# 编译测试
cmake --build build --target test_sha256 test_business_logic

# 运行全部测试
cd build && ctest --output-on-failure

# 或单独运行
./build/test_sha256
./build/test_business_logic
```

注意：`test_business_logic` 需要 `sqlite3.dll`（Windows 上由 CMake 自动复制到输出目录）。

## 5. CMake 集成

测试目标定义在 `cpp/CMakeLists.txt` 末尾，通过 `BUILD_TESTS` 选项门控：

- `test_sha256`：仅依赖 `sha256.cpp`，无外部依赖。
- `test_business_logic`：依赖 SQLite 库，仅在 `SQLITE_LIB` 存在时构建。

两个目标均链接 `GTest::gtest_main`，由 Google Test 提供 `main()` 入口。
