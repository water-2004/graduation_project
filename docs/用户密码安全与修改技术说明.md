# 用户密码安全与修改技术说明

## 1. 模块定位

本改进覆盖两个子任务：

1. **密码哈希存储**（Phase 1）：将明文密码替换为 SHA-256 哈希存储，支持旧明文密码自动升级。
2. **用户密码修改**（Phase 4）：在 Qt 客户端关于页面增加修改密码功能，通过业务服务端完成验证与更新。

## 2. 密码哈希存储

### 2.1 SHA-256 实现

文件：`cpp/src/business/sha256.h`、`cpp/src/business/sha256.cpp`

提供两个接口：

- `Sha256Hex(const std::string& input)` —— 返回小写 64 字符十六进制哈希。
- `IsSha256Hex(const std::string& text)` —— 判断字符串是否为合法 SHA-256 哈希格式。

实现为纯 C++ 代码，不依赖外部加密库，适用于毕业设计演示场景。

### 2.2 登录校验流程

文件：`cpp/src/business/file_repository.cpp` 中的 `ValidateLogin()`

改进前：

- SQL 查询 `WHERE username = ? AND password = ?`，直接比对明文。

改进后：

1. SQL 查询 `WHERE username = ?`，取出存储的密码值。
2. 在 C++ 中计算输入密码的 SHA-256 哈希。
3. 与数据库中存储值比对。
4. **自动升级机制**：如果数据库中存的是明文（非 64 位 hex），则用明文比对；比对成功后自动将明文更新为哈希值。

### 2.3 默认账号与数据导入

- `SeedDefaultUserIfNeeded()`：默认密码 `123456` 以 `Sha256Hex("123456")` 形式入库。
- `ImportLegacyTsvIfNeeded()`：导入旧 TSV 时，对密码字段进行哈希后存储。

## 3. 用户密码修改

### 3.1 后端协议

命令格式：`CHANGE_PASSWORD username|old_password|new_password`

处理流程：

1. 验证旧密码是否正确（同样支持明文自动升级）。
2. 将新密码哈希后更新到数据库。
3. 成功返回 `PASSWORD_OK`。

文件：

- `cpp/src/business/file_repository.h` / `.cpp`：新增 `ChangePassword()` 方法。
- `cpp/src/business/business_logic.cpp`：注册 `CHANGE_PASSWORD` 命令处理器。

### 3.2 客户端协议处理

文件：`widget/graduation_project_widget/business_client.h` / `.cpp`

- 新增 `slot_change_password()` 槽函数。
- 新增 `sig_password_changed()` 信号。
- 在 `HandleLine()` 中解析 `PASSWORD_OK` 响应。

### 3.3 界面交互

文件：`widget/graduation_project_widget/about_page.h` / `.cpp`

- 关于页面新增"修改密码"按钮。
- 点击后弹出 `QDialog`，包含旧密码、新密码、确认新密码三个输入框。
- 校验两次新密码一致后发送 `sig_change_password` 信号。
- 登录成功时通过 `SetCurrentUser()` 保存当前用户名。

### 3.4 信号连接

文件：`widget/graduation_project_widget/mainwindow.cpp`

新增连接：

- `business_client_->sig_login_success` -> `about_page_->SetCurrentUser()`
- `about_page_->sig_change_password` -> `business_client_->slot_change_password`
- `business_client_->sig_password_changed` -> `about_page_->slot_on_password_changed`
- `business_client_->sig_business_error` -> `about_page_->slot_on_business_error`
