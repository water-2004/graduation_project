# 模型性能展示与推理历史技术说明

## 1. 模块定位

本改进覆盖两个子任务：

1. **推理历史记录**（Phase 5）：在实时监测页面增加最近 20 条心拍推理结果的历史表，支持点击回放波形。
2. **模型性能展示**（Phase 6）：在系统概览页面展示当前部署模型的准确率、F1 值、各类别召回率和混淆矩阵。

## 2. 推理历史记录

### 2.1 数据结构

在 `inferpage.h` 中新增：

```cpp
struct BeatHistoryEntry {
    QString time;
    QString pred_label;
    QString confidence;
    QString alert_level;
    QString latency_ms;
    QString source;
    QVector<double> values;  // 波形数据，用于回放
};
```

### 2.2 界面实现

- 在推理页面波形区域下方插入 `QTableWidget`，最大高度 240px。
- 表格列：时间、预测类别、置信度、告警等级、来源。
- 告警等级单元格颜色编码：`critical` 红底、`warning` 橙底。
- 最多保留 20 条记录（`kMaxHistoryEntries = 20`），新记录插入到表头。

### 2.3 数据来源

在以下两个回调中调用 `AddHistoryEntry()`：

- `onPredictResult()`：手动输入推理结果。
- `onBeatResponse()`：样本播放推理结果。

### 2.4 点击回放

点击历史表中任意一行时：

1. 恢复该条记录的波形数据到 `EcgWaveWidget`。
2. 恢复特征文本到输入框。
3. 恢复推理结果字段（预测类别、置信度、告警等级、耗时）。
4. 在日志区输出回放提示。

涉及文件：

- `widget/graduation_project_widget/inferpage.h`（修改）
- `widget/graduation_project_widget/inferpage.cpp`（修改）

## 3. 模型性能展示

### 3.1 数据来源

模型训练阶段生成的评估指标文件：

- 原始路径：`artifacts/paper_optimized_cnn/metrics.json`
- 嵌入资源路径：`widget/graduation_project_widget/data/model_metrics.json`
- Qt 资源 URI：`:/data/model_metrics.json`

### 3.2 展示内容

在系统概览页面底部新增"模型性能指标"区域，包含三个层次：

**总体指标卡片**：

| 指标 | 当前值 |
|------|--------|
| 准确率 (Accuracy) | 97.41% |
| 宏 F1 (Macro F1) | 87.74% |
| 宏召回率 (Macro Recall) | 91.40% |

指标值根据阈值着色：>= 95% 绿色，>= 85% 橙色。

**各类别召回率表**：

| N (正常) | S (室上性) | V (室性) | F (融合) | Q (未知) |
|----------|-----------|---------|---------|---------|
| 98.3% | 82.2% | 93.6% | 85.2% | 97.8% |

低于 85% 的类别标红提示。

**5x5 混淆矩阵**：

- 行标签为真实类别，列标签为预测类别。
- 对角线元素（正确分类）绿底加粗。
- 非对角线误分类元素灰色显示。

### 3.3 实现方式

- 使用 `QFile` 读取 Qt 资源中的 JSON 文件。
- 使用 `QJsonDocument` / `QJsonObject` / `QJsonArray` 解析。
- 在 `DashboardPage::BuildModelMetricsSection()` 中一次性构建 UI。
- 数据在编译时嵌入，不依赖运行时文件路径。

涉及文件：

- `widget/graduation_project_widget/data/model_metrics.json`（新增）
- `widget/graduation_project_widget/resources.qrc`（修改）
- `widget/graduation_project_widget/dashboard_page.h`（修改）
- `widget/graduation_project_widget/dashboard_page.cpp`（修改）

## 4. 当前版本的意义

```text
实时监测页面新增推理历史面板，可回溯最近 20 次心拍检测结果并一键回放波形；系统概览页面集成模型性能指标展示，包含准确率、F1 值、各类别召回率及混淆矩阵，帮助用户直观评估当前部署模型的诊断能力。
```
