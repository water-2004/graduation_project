# Qt 登录模块运行说明

## 1. 当前功能

当前 Qt 客户端已经支持：

1. 启动后先显示登录页
2. 连接业务服务端 `business_service`
3. 使用账号密码登录
4. 登录成功后进入实时监测页面

## 2. 启动前准备

请先启动业务服务端：

```powershell
F:\graduation_project\build\cpp\Release\business_service.exe
```

默认监听：

- 地址：`0.0.0.0`
- 端口：`9200`

默认管理员账号：

- 用户名：`admin`
- 密码：`123456`

## 3. Qt 客户端登录页默认值

Qt 登录页当前默认填写：

- 业务服务端地址：`127.0.0.1`
- 业务服务端端口：`9200`
- 用户名：`admin`
- 密码：`123456`

## 4. 登录步骤

1. 启动 `business_service`
2. 启动 Qt 客户端
3. 在登录页点击“登录系统”
4. 登录成功后自动进入监测页

## 5. 当前注意事项

1. 登录页连接的是 `business_service`
2. 监测页连接的是 `edge_infer_service`
3. 当前这两个服务是分开的，分别负责不同功能

也就是说：

- 登录成功，不代表已经连接推理服务
- 进入监测页后，仍然需要按原流程连接 `edge_infer_service`

## 6. 当前模块边界

当前系统已经初步形成两条客户端连接：

1. 业务服务连接：登录、病人管理、历史记录
2. 推理服务连接：实时推理、波形显示、样本播放

后续病人管理模块会继续复用当前登录使用的业务服务连接。

登录模块完成后，下一步建议继续实现：

1. 病人管理页面
2. 登录后病人列表加载
3. 选择病人后再进入监测流程
